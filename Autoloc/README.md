# AutoLoc - Plateforme de gestion de location de véhicules multi-agences

## Objectifs du projet
Ce projet vise à développer une plateforme complète de gestion de location de véhicules pour les agences AutoLoc, en utilisant Spring Boot, MySQL et une architecture MVC.

## Acteurs identifiés (Séance 1)
* Client
* Agent d'agence
* Responsable d'agence
* Administrateur
